Slide 2: Role Definitions

Core Components: From "Talking" to "Doing"

OpenClaw

OpenClaw is a local-first AI agent and personal assistant platform that orchestrates LLMs, Skills, MCP tools, RAG, and Memory into a full agent loop from "talking" to "doing."

LLM (Reasoning Brain)

The LLM is the reasoning brain inside OpenClaw. It interprets user intent, plans actions, and decides when to call which tools.

MCP (Tool Bus)

MCP establishes a unified "tool bus" between LLMs and external tools—often described as the "USB port of the AI world."

Slide 4: Governance & Guardrails

Operating Framework: Dos and Don'ts

Governance: The Must-Dos

Review Sources & Permissions

Audit Skill sources. Beware of prompt injection, tool poisoning, or unsafe community handling.

Apply Least Privilege

Limit API keys and OAuth scopes. Use scoped permissions and detailed execution logging.

Human-in-the-Loop

Require explicit approval for high-risk actions: system commands or production file deletion.

Guardrails: What to Avoid

Treat as Fully Correct

It is not an autonomous employee. Model reasoning can be misapplied or logically incorrect.

Install Untrusted Skills

Avoid mass installation, specifically skills involving browser automation or shell commands.

Ungoverned Action

Never allow direct action on production environments without strict audit logging and isolation.
