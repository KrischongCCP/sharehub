SmarTier for Public Folder

Email Archiving & Tiering

Automatically archive, tier, and ensure compliance for business-critical data.

Works with Microsoft 365, Exchange, and IMAP/POP3 servers

SmarTier for Public Folder is a solution designed to extract, archive, and manage data from email systems like Microsoft Exchange and M365 Email. It addresses the challenges of large, unstructured public folders by moving their content to more cost-effective storage while keeping it accessible and searchable.

How It Works: A Clear, Automated Process

Email Extraction

A middleware component connects to the email source (like Exchange 2016 or M365 Email) and performs scheduled extractions of email data.

Cloud Native Support

As a SaaS solution, SmarTier is built on a cloud-native, microservices architecture, running on Kubernetes for scalability and resilience.

Indexing & Storage

All extracted content is indexed and tagged, then moved to an economical object storage solution, such as AWS S3 or an on-premise system.

User Access

End-users can access the archived data through a Web UI, which allows them to view mail, search the archive, and download emails for offline use.

Key Features

Automated Archiving It allows for policy-based archiving using customizable rules such as date, size, and metadata. It can also identify and archive Redundant, Obsolete, or Trivial (ROT) data.
Granular Selection Policies can be applied at different scopes, such as site, library, or folder.
Monitoring and Reporting A real-time dashboard provides visibility into archiving activity, storage savings, and rule coverage.
Security and Auditing The system provides end-to-end encryption for data in transit and at rest, along with full audit trails for all archiving and restore activities.
