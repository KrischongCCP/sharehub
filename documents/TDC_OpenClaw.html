Slide 2: Role Definitions

Core Components: From "Talking" to "Doing"

OpenClaw

OpenClaw is a local-first AI agent and personal assistant platform that orchestrates LLMs, Skills, MCP tools, RAG, and Memory into a full agent loop from "talking" to "doing."

LLM (Reasoning Brain)

The LLM is the reasoning brain inside OpenClaw. It interprets user intent, plans actions, and decides when to call which tools.

MCP (Tool Bus)

MCP establishes a unified "tool bus" between LLMs and external tools—often described as the "USB port of the AI world."

Skill (Modular Capability)

A Skill is a modular capability package that tells the agent what tools exist, how to use them, and what specific workflows to complete.

Platform Management

Slide 4: BEST PRACTICES

Governance & Safety: The Must-Dos

Review Sources & Permissions

Audit Skill sources. Community materials are curated, not audited; beware of prompt injection, tool poisoning, or unsafe handling.

Apply Least Privilege

Install only required Skills. Limit API keys, OAuth scopes, and file access. Use scoped permissions and detailed logging.

Define Clear Boundaries

Run within local, workspace-scoped, or controlled cloud infrastructure. OpenClaw has read/write and external tool connectivity.

Human-in-the-Loop

Require approval for high-risk actions: sending emails, production setting changes, shell commands, or file deletion.

Slide 5: RISK MITIGATION

Operational Guardrails: What to Avoid

Treat as Fully Correct

It is not an autonomous employee. Behavior depends on model reasoning and tool outputs, which can be misapplied or incorrect.

Install Untrusted Skills

Avoid mass installation, specifically skills involving browser automation, system commands, finance, or credential handling.

Default Data Exposure

Don't expose customer data, API secrets, or contracts to every workflow. Keep production database access restricted.

Ungoverned Production Action

Never allow direct action on production environments without strict logging, manual approval, and environment isolation.
